# SL Selfish — Content Automation & Pipeline Suite

An automated workflow and processing utility designed for structured web novel parsing, serialization, and pipeline integration.

## Key Features
- **Extraction Engine:** Automated chapter traversal and content ingestion.
- **Normalization:** Cleans and formats content structures for downstream media processing.
- **Modular Pipeline:** Easily connects with speech synthesis or storage modules.
